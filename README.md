# Image Search Engine

An image search engine with real-time results, curated images, and source redirection. Built with HTML, CSS & JavaScript, and integrates the Shutterstock API.

## Features
- Real-time search
- Curated results
- Source redirection
- API powered

## Setup
1. Clone the repo: `git clone ...`
2. Obtain API key from Shutterstock
3. Add API key to `script.js`
4. Open `index.html` in your browser

## Usage
Enter a search term and view results instantly.

## File Structure
- `index.html` – main page
- `script.js` – app logic
- `style.css` – styles
